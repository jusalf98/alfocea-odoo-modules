# Alfocea Odoo Modules

This repository contains a collection of custom Odoo modules developed by **Justo Alfocea Frutos**. The modules add new features to Odoo and extend its standard behaviour.

## Odoo version

The modules target **Odoo 18.0**.

## Conventions

- The technical name of every module starts with the `alfo_` prefix.
- The modules follow the [Odoo Community Association (OCA)](https://github.com/OCA) and Odoo SA development guidelines.
- Each module includes its own `readme/` folder with a description and usage notes, and its own tests.

## Installation

1. Clone this repository into your Odoo addons directory:

   ```bash
   git clone https://github.com/jusalf98/alfocea-odoo-modules.git
   ```

2. Add the repository path to the `addons_path` option of your Odoo configuration file.
3. Restart Odoo and update the Apps list.
4. Search for the module you want and install it.
